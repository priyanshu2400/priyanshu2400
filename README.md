## 👋 About Me

I'm a software engineer on an **SRE tooling** team. I build the platforms other engineers lean on when something breaks in production: **observability pipelines** that tie logs, metrics and traces together, and **bare-metal provisioning automation** that manages firmware across **25,000+ servers** in on-prem data centers.

My day-to-day is **Go and Python**, REST APIs, OpenTelemetry, and a lot of Linux. I like the unglamorous parts of infrastructure: making failures easy to find, and making slow manual processes fast.

## 🚀 What I've Built

| | Impact |
|---|---|
| 🔭 **Centralized observability platform** | Scaled it across **3 production regions**, unifying metrics, traces and logs from major internal cloud services into one place |
| 🔗 **Cross-service trace correlation** | A shared trace ID across the whole request cut cross-component debugging time by **90%** |
| 🧩 **Zero-code instrumentation SDK** | Built on OpenTelemetry; services onboard in minutes and manual instrumentation effort dropped by **85%** |
| 🍴 **Gunicorn/uWSGI fork-safety for OTel metrics** | Post-fork meter re-initialization hooks plus PID drift detection fixed metrics going dead after fork |
| 🔐 **Team-level RBAC for telemetry** | Isolated telemetry data ownership across teams |
| 🖥️ **Bare-metal firmware pipeline** | Redesigned the firmware upload flow, taking upgrades across ~25,000 servers from **days to minutes** |
| 📡 **Nginx access-log tailer in Go** | Exposed proxy-level request drops that application APIs couldn't see |
| 🕸️ **Live service dependency graphs** | Upstream/downstream call chains with live load percentages via OTel request hooks |
| 📊 **Grafana automation + SSO** | Dashboards generated on service registration, no manual setup or repeated logins |
